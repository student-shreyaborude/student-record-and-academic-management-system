About the project
A console-based application that stores, organizes, updates and retrieves student academic information using Python's built-in collections. It follows the workflow: problem understanding → algorithm → flowchart → pseudocode → implementation → testing → documentation.
Features
Add, search (by roll number), update and delete student records
Display all records
Calculate each student's average, grade, and the class average
Find the highest scorer
List students by department and count students (overall and per department)
Generate a ranked report
Input validation (name, e-mail, phone, department, marks 0–100, duplicates)
How each collection is used
Collection
Used for
String
Names, departments, addresses, e-mail IDs
List
The list of all student records, subjects, marks, attendance
Tuple
Identity data (roll_no, reg_no, date_of_birth) — immutable
Set
Valid departments, subjects, and student clubs (unique values)
Dictionary
Complete student profile (and nested contact information)

How to run
# 1. Clone the repository
git clone https://github.com/student-shreyaborude/student-record-management-system.git
cd student-record-management-system

# 2. Run the application (interactive menu)
python student_management.py

# 3. Run the demo with sample data
python demo_data.py

# 4. Run the collection exercises
python exercises.py

# 5. Run the automated tests
python -m unittest discover -s tests -v
